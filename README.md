## About me

I'm a Software Development student at **Hogeschool Utrecht** and an intern at **AFAS Software**. I like building things people actually use, and I like knowing how they run underneath, from the code to the server.

## My best work: Scouting Het ZuiderKruis

I've been a leader at [Scouting Het ZuiderKruis](https://zuiderkruis.nl) since 2023. It's a water scouting group in Hilversum with boats, sails and a clubhouse. I'm also the one who builds and hosts the group's software, for real users who depend on it every week.

The **Soos** is our bar, and I built the site where members order their drinks and food. **Acties** is where the group runs its fundraising actions and activities, with online ordering and payments, built with Laravel and React. I also host the group's website. The group's organisation is on [GitHub](https://github.com/Scouting-Zuiderkruis).

## Right now

I'm doing my internship at AFAS Software and studying HBO ICT Software Development at HU. On Saturdays I'm at scouting, and in between I tinker with Home Assistant, my home lab and Satisfactory server tooling. For fun I play Minecraft with the Create mod.

## Tech I work with

<img src="https://skillicons.dev/icons?i=laravel,php,react,ts,js,java,py,cs,dotnet,nodejs,django,mysql,postgres,mariadb,docker,nginx,linux,git,github,githubactions,gitlab&perline=11" alt="Laravel, PHP, React, TypeScript, JavaScript, Java, Python, C#, .NET, Node.js, Django, MySQL, PostgreSQL, MariaDB, Docker, Nginx, Linux, Git, GitHub, GitHub Actions, GitLab" />

My main stack is Laravel and React with Mantine, in PHP and TypeScript. I also work with JavaScript, Java, Python, C# and .NET, Node.js and Django, and keep my data in MySQL, PostgreSQL or MariaDB.

I run my own servers on Linux with Docker, Proxmox, Nginx and Virtualmin, watched by Uptime Kuma. Pi-hole, Home Assistant and restic backups keep the rest in order. For code I use Git, GitHub with Actions, and GitLab. For fun I use Unreal Engine and mod Minecraft with Gradle.
